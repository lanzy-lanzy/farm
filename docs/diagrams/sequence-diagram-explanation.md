# Poultry Farm App — Module Interaction

| Module | Interacts With | What Happens |
|---|---|---|
| **Login** | Dashboard | Staff signs in, sees farm overview |
| **Flocks** | Dashboard | Add/edit/delete chicken batches; dashboard shows total count |
| **Feeding** | Inventory, Notifications | Log feeding; feed stock auto-deducted; low-stock alert if needed |
| **Eggs** | Dashboard | Log daily egg counts; dashboard shows production stats |
| **Mortality** | Flocks | Record deaths; flock headcount auto-updated |
| **Medicine** | Inventory, Notifications | Log medicine/vaccine use; stock deducted; vaccination reminder set |
| **Sales** | Dashboard | Record product sales; dashboard shows revenue |
| **Expenses** | Dashboard | Record expenses; dashboard shows costs |
| **Reports** | Dashboard | View/export production, sales, expenses, mortality, inventory, profit/loss |
| **Notifications** | Staff | Alerts for low stock, expired items, upcoming vaccinations |
